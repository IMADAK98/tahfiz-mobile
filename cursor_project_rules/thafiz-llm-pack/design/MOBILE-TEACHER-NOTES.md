## 2. المصادقة (Auth)

| تدفق | API / سلوك | فجوة الملاحظة |
|---|---|---|
| **Login** | `POST auth/login` → Bearer tokens في secure storage؛ `auth/refresh` | **OK** مع `imadka224@gmail.com` → الرئيسية. UI: `04-login.png`. إقلاع قد يمر بسبنر (`03`). |
| **Register** | مسار `/register` + `TeacherSignupRequestModel` + `pending-teacher-request` | موافقة المشرف قبل الدخول الكامل محتملة |
| **Recover** | `auth/mobile/request-password-reset` → OTP → `auth/mobile/reset-password`؛ شاشة `RecoverAccount` + `OtpVerification` | مسار باسم `revoverAccount` (typo) |

**أدوار العميل:** `teacher` / `student` في الـ binary؛ **لا admin** في تطبيق الجوال. الطالب يظهر ككيان يُدار من واجهة المعلّم أكثر من تطبيق طالب مستقل.

### Login مُشاهد (`04-login.png`)
- عنوان: **تسجيل الدخول**
- شعار كتاب أخضر دائري + **مرحباً بك** / **سجل دخولك للمتابعة**
- حقول: **البريد الإلكتروني** · **كلمة المرور** (مع إظهار/إخفاء)
- زر أساسي أخضر: **تسجيل الدخول**
- روابط: **ليس لديك حساب؟ سجل الآن** · **نسيت كلمة المرور؟**
- Logcat أثناء الجلسة: تحذيرات `FlutterSecureStorage` («Stored key cannot be decrypted…») — قد تفسّر سلوك الجلسة/الإقلاع

**ما زال مطلوباً من Explorer:** لقطات Register / Recover / OTP + بوابة «طلب معلّق» إن وُجدت.

## 6. الحضور اليومي (ملخص سلوكي)

1. المعلّم يفتح حلقة ← تاريخ ← قائمة طلاب.  
2. **تعديل** يفعّل مفاتيح حاضر/غائب/متأخر/معذور.  
3. الحفظ عبر bulk attendance.  
4. طلاب بلا علامة يبقون `NOT_MARKED` في roster/weekly-table؛ **التجميع الإداري** قد يُظهر قائمة فارغة إن لم تُعلَّم أي صفوف — هذا ليس «لا يوجد طلاب» (انظر `attendance-vs-progress.md`).  
5. التقارير الإدارية على الويب = قراءة فقط؛ الكتابة هنا على الجوال.

### خلل حرج — بوابة التقدّم vs حضور غير مُلتزَم
- الضغط على صف التقدّم (الحفظ/المراجعة/التثبيت) يُظهر snackbar أحمر: **«يرجى تحديد حالة الحضور أولاً»**
- ذلك **رغم** أن شريحة **حاضر** محدّدة بصرياً بالأخضر (`07-progress-blocker-snackbar.png`).
- الفرضية التصميمية/الهندسية: تمييز الشريحة ≠ حالة حضور **محفوظة/مُلتزَمة**؛ قد يلزم ضغط **تعديل**/حفظ أولاً، أو الشريحة لا تكتب الحالة التي تفحصها بوابة التقدّم.
- أُعيد تأكيده محلياً 2026-09-10 (`17-progress-blocker-snackbar.png`).
- **أثر على أي إعادة تصميم جوال:** اجعل مسار الحضور→التقدّم صريحاً (حفظ تلقائي عند اختيار الشريحة، أو عطّل التقدّم حتى يُحفظ الحضور مع رسالة أوضح، أو اربط البوابة بنفس state الظاهر).
